## What actually runs today (no hardware needed)

- `cd hub && python3 -m foundationhub` — boots to the LOGIN screen; register an
  account (setup code `1234` above guest) and sign in. Dev knobs:
  `FOUNDATIONHUB_USERS=<path>` for a writable registry, `FOUNDATIONHUB_USER=<name>` to skip
  login.
- `cd frank && python3 -m pytest` — rule engine, enforcement (now incl.
  per-user `UserEnforcers` + lockstate v2/public-summary tests), triage,
  Overseer `Rulebook`, and voice (`mistral.py`) tests (100 tests total).
- `cd hub && python3 -m pytest` — notes suite (editor buffer ops, soft-wrap,
  tag parsing, slugs, search) + file manager backend (path-scoping guard,
  size formatting, listing, operation planning) + system monitor `/proc`
  parsers (CPU%, meminfo, uptime, loadavg, net/dev, process rows) (99 tests).
- `cd media && python3 -m pytest` — media player logic (playlist queue, library
  scan + per-user dirs, PCM volume/time, WAV decode + seek, player state
  machine on fake decoder/output engines) (42 tests).
- `cd media && python3 -m foundationmedia` — the player TUI runs off-device
  (empty library on first run; playback honestly reports no ALSA off-target).
- `python3 -m frankd.rules --selftest` — dumps how sample events are classified.
